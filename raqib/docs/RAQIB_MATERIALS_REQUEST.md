# Raqib — materials we need from you / المواد المطلوبة منكم

Nothing below can be invented by us: each item is a rule or content that belongs to your organization. Until it arrives, the system keeps the mechanism and leaves the value empty or marked "assumed". Send each item in any readable form (Word, Excel, PDF, photo of the paper); the templates below only show what we need to know.
لا يمكننا افتراض أي بند هنا لأنه يخص جهتكم. حتى وصوله يبقى النظام جاهزًا بالآلية مع ترك القيمة فارغة أو معلَّمة «مفترضة». أرسلوا كل بند بأي صيغة مقروءة؛ النماذج أدناه توضح المعلومة المطلوبة فقط.

## 1. Original inspection forms / نماذج التفتيش الأصلية
For each form: its name and number, version/date, and every item in order, with its group, what the inspector answers (compliant / non-compliant / not applicable, or other), and any observation points.
لكل نموذج: الاسم والرقم والإصدار، وكل بند بترتيبه ومجموعته وطريقة الإجابة ونقاط الملاحظة.

|---|---|---|---|---|---|---|
| | | | | | | |

## 2. Deduction table (scoring from 100) / جدول الخصم (الدرجة من ١٠٠)
Per item or per severity: how many points are deducted; any cap per item or per form; who is allowed to maintain the table.
لكل بند أو درجة خطورة: عدد النقاط المخصومة، وأي حد أقصى، ومن يحق له تعديل الجدول.

| Item or severity / البند أو الخطورة | Points deducted / النقاط المخصومة | Cap / الحد الأقصى | Notes |
|---|---|---|---|
| | | | |

## 4. Escalation (3 / 6 / 9 days) / التصعيد
- Counted in calendar days or working days? / أيام تقويمية أم أيام عمل؟ ______
- Counted from assignment or from the due date? / من الإسناد أم من تاريخ الاستحقاق؟ ______
- Who is notified at each level? / من يُبلَّغ في كل مستوى؟ Day 3: ______ Day 6: ______ Day 9: ______
- What counts as high severity (notified immediately)? / ما الذي يُعد خطورة عالية؟ ______

## 5. Quality standards and MOI requirements / معايير الجودة ومتطلبات MOI
The documents themselves (or the clauses to embed), and where in the inspection or report each must appear.
الوثائق نفسها (أو البنود المطلوب تضمينها) وأين يجب أن تظهر في التفتيش أو التقرير.

## 6. Organization name and logo / اسم الجهة والشعار
- Name in Arabic and English / الاسم بالعربية والإنجليزية: ______________________
- Logo file, PNG or JPEG, ideally with a transparent or white background / ملف الشعار PNG أو JPEG
  (you can upload it yourself in Settings → Organization / يمكنكم رفعه من الإعدادات ← المؤسسة)

## 7. Training approval path / مسار اعتماد التدريب
Confirm or change: supervisor request → Project Manager → Quality; guard request → supervisor review → Project Manager → Quality. Is the supervisor review of guard requests required? Who may skip a step, if anyone?
أكدوا أو عدّلوا المسار، وهل مراجعة المشرف لطلبات الحراس إلزامية، ومن يحق له تجاوز خطوة إن وُجد.

## 8. Commercial items (not technical) / بنود تجارية
- Price and how it is split between the two stages / السعر وتقسيمه على المرحلتين
- Duration of each stage / مدة كل مرحلة
- Length of the bug-fix period after delivery / مدة معالجة الأخطاء بعد التسليم
- Dates for acceptance / مواعيد الاستلام
- Who pays and registers hosting, domain, e-mail and storage / من يتولى الاستضافة والنطاق والبريد والتخزين

## 9. Optional / اختياري
Different ranking weights if equal importance for the four indicators is not what you want (Settings → Project ranking).
أوزان ترتيب مختلفة إن لم تريدوا تساوي المؤشرات الأربعة.
